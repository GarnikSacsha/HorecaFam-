# Аудит продукта HoReCaFam — 2 ноября 2026

Источник: стейджинг `web-staging-4268.up.railway.app`, код и документация репозитория.
Просмотрено под аккаунтом Дениса (админ + оператор платформы) и аккаунтом официанта
(Олександра Гарнік, сертифицирована). Живой web-бандл `index-CbWKJwSA.js` содержит CRA-275
(«Як розповісти гостю»), но не содержит статей CRA-288. Фиксы ведутся в ветке
`fix/ux-audit-2026-11` поверх `feature/multi-role-training-content` (18e1f68).

## Общая оценка

Инженерия сильная: ~42k строк backend, ~34k строк тестов, ~21k frontend, покрытие ~94%,
мультитенантная модель (Organization/Location). Основной путь «выучил меню → практика →
финал → сертификат → админ видит результат» работает: 4 сотрудника, 3 сертифицированы.
Слабые места — процесс, доставка и содержание, а не код.

## Что работает хорошо

- Дашборд админа и «Результати» понятны с первого взгляда.
- Мобильный кабинет официанта: нижняя навигация, главная показывает статус и следующий шаг.
- Практика: последний и лучший результат, повтор без ограничений.
- Карточка блюда: цена, аллергены, оригинальное описание.
- Ошибок в консоли нет, API быстрые.
